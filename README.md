## 📖 第一章：新手入门与快速上手

### 1.1 系统要求
- **操作系统**：Windows 10 / Windows 11 (64-bit)
- **运行内存**：推荐 4GB 及以上
- **存储空间**：至少预留 500MB 可用磁盘空间

### 1.2 首次安装与启动
1. 双击运行 `deepcloud-ui Setup 0.2.11.exe`；
2. 选择软件安装路径（默认安装至用户目录，亦可自由选择非系统盘）；
3. 安装完成后启动 DeepCloud，微内核网关将自动在安全环回接口（`127.0.0.1`）初始化启动；
4. 客户端将静默完成 SQLite 本地数据库建表与出厂沙箱运行环境初始化。

### 1.3 界面导航速览
- **海阔视界 (`/hk-vision`)**：小程序运行容器、聚合搜索与影音播放中心；
- **媒体中心 (`/media`)**：影视、音频、漫画与网盘媒体资源库；
- **插件市场 (`/market/plugins`)**：AList 多网盘挂载、Rclone 存储、本地爬虫与 Sidecar 守护进程；
- **系统设置 (`/settings`)**：外观主题、更新检查、安全凭证与全局偏好配置。

## 🎬 第二章：海阔视界 (Hiker) 小程序完全使用教程

海阔视界运行引擎是 DeepCloud 桌面端的核心支柱之一，支持在纯 Node.js / Web Worker 原生沙箱中秒级执行成千上万个海阔视界小程序与视频解析规则。

### 2.1 小程序规则的三种导入方式

#### 方式一：智能剪贴板一键嗅探导入（最简单常用）
1. 在浏览器、社区或群聊中复制任意海阔视界分享口令（例如以 `￥rule￥`、`￥import￥` 包裹的代码，或以 `hiker://` 开头的分享口令）；
2. 切换回 DeepCloud 客户端窗口，系统将自动弹出**「检测到海阔规则口令」**确认卡片；
3. 点击 **「确认导入」**，规则即可瞬间安装至本地。
> [!NOTE]
> DeepCloud 内置防误判过滤算法，复制纯文本日志或错误堆栈时不会触发干扰弹窗。

#### 方式二：本地文件导入
1. 点击左侧主导航进入 **「海阔视界」**；
2. 点击右上角 **「导入」 $\to$ 「导入本地文件」**；
3. 选择包含规则定义的 `.json` 或 `.txt` 规则备份文件，系统将智能解析并批量导入。

#### 方式三：远程网络订阅链接
1. 点击右上角 **「订阅管理」**；
2. 粘贴云端规则订阅 URL（支持 GitHub Raw、Gitee 或自建 Web 服务器链接）；
3. 点击 **「同步订阅」**，软件将自动更新规则并在后台按策略维护最新版本。

---

### 2.2 小程序浏览与使用操作

1. **进入小程序**：在「海阔视界」列表页点击任意小程序卡片（如“玩偶哥哥”、“星集Media”等）；
2. **多级栏目导航**：小程序顶部通常具有分类标签或横向滚动按钮（电影、剧集、动漫、综艺等），点击即可实时刷新列表；
3. **沉浸式选集**：点击影视海报卡片进入二级详情页，即可查看简介、评分，并在播放源线路之间自由切换。

---

### 2.3 小程序内输入框与搜索使用指南

在很多小程序首页（例如「玩偶哥哥」），开发者设计了原生搜索输入框：

```
┌──────────────────────────────────────────────┬────────┐
│  🔍 请输入搜索关键词...                     │ [搜索] │
└──────────────────────────────────────────────┴────────┘
```

1. **输入关键词**：直接在输入框中键入要查找的影视剧名（如“庆余年”、“凡人修仙传”）；
2. **触发搜索**：
   - 方式 A：直接按下键盘 <kbd>Enter</kbd>（回车键）；
   - 方式 B：点击输入框右侧的蓝色放大镜图标；
3. **搜索结果呈现**：
   - 软件将在 Worker 沙箱中自动评估搜索表达式并生成导航目标；
   - 系统自动对齐全局搜索词，并即时拉取该源站点的全量搜索结果列表；
   - 点击左上角的 **「返回」** 按钮，即可无缝返回该小程序首页，浏览记录完好保留。

---

### 2.4 原地脚本 vs 二级页面跳转的区别

海阔视界生态中包含两种不同的交互组件：
- **原地交互组件（如「云盘君.简」提取码/Cookie 设置）**：
  - 此类输入框用于在本地保存变量配置（通过 `putMyVar` / `setPageParams`）；
  - 输入后点击确认，页面会**原地刷新**更新状态，**绝不开辟新页面帧，绝不会将参数误判为剧名跳转**。
- **页面跳转组件（如选集卡片、搜索入口）**：
  - 点击后平滑推入新页面帧（二级详情、播放页或搜索结果页），支持完整的历史后退栈。

## 🍿 第三章：旗舰影音播放器使用教程

DeepCloud 内置专为大屏与桌面端量身定制的高性能沉浸式影音播放器，集成硬件加速、Top Layer 穿透菜单与开放弹幕系统。

### 3.1 核心播放控制快捷键速查表

| 按键 | 功能说明 | 补充备注 |
| :--- | :--- | :--- |
| <kbd>Space</kbd>（空格） | **播放 / 暂停** | 随时切换播放状态 |
| <kbd>←</kbd> / <kbd>→</kbd> | **快退 5 秒 / 快进 5 秒** | 长按支持连续平滑快进快退 |
| <kbd>Ctrl</kbd> + <kbd>→</kbd> | **快进 30 秒** | 快速跳过片头 |
| <kbd>↑</kbd> / <kbd>↓</kbd> | **音量增加 / 减少 5%** | 屏幕右上角同步展示当前音量百分比 |
| <kbd>F</kbd> | **进入 / 退出全屏幕** | 支持双击画面空白区域全屏 |
| <kbd>M</kbd> | **静音 / 恢复声音** | 一键瞬间静音 |
| <kbd>D</kbd> | **显示 / 隐藏弹幕** | 一键切换弹幕总开关 |
| <kbd>[</kbd> / <kbd>]</kbd> | **上一集 / 下一集** | 自动按选集列表顺序连续播放 |
| <kbd>Esc</kbd> | **退出全屏 / 关闭弹层** | 优先关闭打开的菜单面板 |

---

### 3.2 W3C Top Layer 沉浸式菜单穿透系统

在传统的桌面播放器中，进入全屏模式后常常出现右键菜单被视频画面覆盖、设置面板弹不出的问题。DeepCloud 彻底攻克了该难题：
- **菜单全穿透**：全屏状态下点击底栏的 **「画质」、「播放线路」、「倍速」、「比例」、「DLNA」** 按钮，菜单将优雅向上弹出并穿透至顶级渲染层；
- **防误触锁定**：当菜单展开时，悬浮控制栏将自动锁定常驻，键盘快捷键临时静默，防止在调节参数时误触快进或暂停。

---

### 3.3 弹弹play 官方 API v2 开放弹幕平台

播放器原生打通弹弹play 官方开放弹幕库：
1. **自动指纹匹配**：播放视频时，播放器自动提取文件前 16MB 流式哈希与剧集正名，精准向弹弹play 云端检索匹配剧集编号；
2. **海量多源弹幕汇总**：自动拉取 B站、爱奇艺、腾讯视频、优酷等多平台汇总弹幕，无需手动下载外部 `.xml` 弹幕文件；
3. **手动修正匹配**：若遇到冷门资源未自动匹配，可在播放器右侧点击 **「弹幕匹配」**，手动输入剧名与集数重新关联。

---

### 3.4 弹幕即时发射与视觉个性化定制

#### 发射个人弹幕
- 在播放器控制栏中央的弹幕输入框中输入留言，按 <kbd>Enter</kbd> 即可发射；
- 支持切换弹幕形态：**滚动弹幕**、**顶部固定**、**底部固定**；
- 支持自定义弹幕字体颜色（内置 8 款经典高饱和对比色）。发射的弹幕不仅立即高亮上屏，还会自动异步上报给弹幕库与同好共享。

#### 弹幕视觉参数调整（齿轮设置）
- **字号大小**：支持 12px ~ 48px 平滑无级滑块调节；
- **不透明度**：支持 20% ~ 100% 透明度调节，既能看清弹幕又不遮挡关键剧情；
- **字幕避让模式 (Subtitle Safe Area)**：开启「避让字幕区域」后，弹幕将自动避开屏幕底部 18% 的区间，告别弹幕遮挡字幕的烦恼！

---

### 3.5 局域网大屏投屏 (DLNA Cast)

1. 确保电脑与客厅电视/投影仪处于同一个 Wi-Fi 或局域网内；
2. 点击播放器底栏右侧的 **「投屏 (DLNA)」** 按钮；
3. 系统将通过 SSDP 协议自动探测局域网内的智能电视设备；
4. 点击设备名称，视频流将即时推流至电视大屏播放，电脑端可充当遥控器进行进度与音量调节。

## 🗄️ 第四章：AList 多网盘挂载与 4K 直连播放

DeepCloud 通过通用 Sidecar 守护进程管理器，原生内置了 AList 多网盘挂载生态。

### 4.1 启用 AList 守护进程
1. 点击左侧主导航进入 **「插件市场」**；
2. 找到 **AList 服务** 卡片，点击 **「启用」**；
3. 系统后台将自动启动轻量级 `alist.exe` 守护进程，并在端口 `127.0.0.1:5244`（支持冲突自动漂移）建立微网关映射。

### 4.2 挂载常用网盘
1. 点击插件卡片中的 **「进入控制台」**；
2. 在 AList 后台的「存储」设置中，添加您拥有的网盘：
   - **阿里云盘 / 夸克网盘**：通过手机端扫码或输入移动端 Token 即可轻松挂载；
   - **百度网盘 / 115网盘 / 天翼云盘 / WebDAV**：按引导填入账户凭证即可接入；
3. 挂载完成后，所有网盘内的文件夹将被聚合为虚拟统一文件系统。

### 4.3 零下载秒播 4K 原画
- 在 DeepCloud 中进入 **「媒体中心」 $\to$ 「网盘挂载」**；
- 即可像浏览本地文件夹一样浏览数 TB 的网盘视频，点击即可调用内置播放器以原画直链播放，免去漫长的下载等待时间。

## 💡 第五章：桌面悬浮工具、离线 OCR 与 AI 助手

### 5.1 桌面悬浮视窗
- **唤出方式**：点击右侧边缘贴边浮标，或按下全局自定义快捷键（默认 `Ctrl + Shift + Space`）；
- **形态收缩**：悬浮工具栏支持迷你悬浮球与展开工具条两种形态，支持自由拖拽位置。

### 5.2 屏幕截图与离线 PaddleOCR
1. 点击悬浮工具条上的 **「截图 OCR」** 图标；
2. 鼠标框选屏幕任意区域（包含视频画面、网页、PDF 等）；
3. 内置的离线 PaddleOCR 引擎将在毫秒内识别图片中的全部文字，无需联网，隐私零泄露；
4. 识别结果支持一键复制到剪贴板，或一键发送给 AI 助手。

### 5.3 划词即问与大模型对话
- 选中文本后点击 **「AI 提问」**，悬浮视窗将展开智能体对话抽屉；
- 在「系统设置」中配置好 OpenAI / DeepSeek / Claude / Ollama 本地模型 API Key 后，即可实现选中文本翻译、长文摘要、代码解释与知识问答。

## 🔄 第六章：常见问题与故障自愈 (FAQ)

### Q1：升级时提示版本已是最新，如何手动强制更新？
**答**：
- 进入「设置」 $\to$ 「通用设置」，确认更新仓库地址为 `Mowen559/deepcloud-releases`；
- 点击「检查更新」按钮旁边的「刷新」，系统将自动绕过本地缓存直接探测 GitHub 最新 Release；
- 您也可以直接从本页面下载最新的 `deepcloud-update-v0.2.11.asar`，在设置页点击「从本地文件加载补丁」一键更新。

### Q2：播放某些视频提示“播放失败”或一直转圈？
**答**：
1. **切换播放线路**：在播放器控制栏点击「线路」，很多小程序提供多条切片线路，选择速度更快的备用线路；
2. **关闭硬件解码**：在播放器设置面板中尝试开启/关闭「硬件加速解码 (DXVA2/D3D11VA)」，部分老旧显卡关闭硬解后可恢复正常；
3. **网盘直链过期**：若为网盘分享链接，请在小程序页面点击一次「刷新」，重新换取有效的最新下载 Token。

### Q3：规则内搜索输入框点击无反应？
**答**：
- 请确认已安装 **v0.2.11** 或更新版本；
- 本版本已彻底重构输入框的事件转发机制与 Worker 沙箱语法转义，输入关键词后敲击回车即可直接搜索。
